# VRC-BoardGameKit (仮称)

**VRChat向け 汎用ボードゲーム・カードゲーム制作パッケージ**

---

## 概要

本プロジェクトは、VRChatワールドでオリジナルのカードゲーム・ボードゲームを誰でも簡単に遊べるようにするための汎用パッケージツールです。

- **サンドボックス型基盤**: トランプやオリジナルカードを直感的に「引く・配る・手札を見る・場に出す・シャッフルする」基本動作を標準装備。
- **自作ゲーム・オリジナルルール対応**: カード画像や枚数の自由な差し替えはもちろん、Local LLMなどを活用して独自ルール（役判定やターン進行）を低コストで拡張できるプラグイン設計を採用。
- **VPM (VRChat Package Manager) 公式規格対応**: VCC経由でワンクリック導入可能。

---

## 主な機能

1. **カード＆デッキ管理**
   - 山札（デッキ）のシャッフル・ドロー・リセット
   - 捨て札（ディスカードパイル）の集約
   - 任意の枚数・カード画像テクスチャの差し替え
2. **手札秘匿化システム**
   - プレイヤー手札トレイ（本人のみ表面が見え、他プレイヤーには裏面に見える視認制御）
3. **プレイヤー＆座席システム**
   - `VRCStation` 連動（椅子に座ると手札トレイと操作権限が割り振られる）
4. **プレイエリア＆スナップ配置**
   - 場の指定エリアへのカード整列・スナップ
5. **汎用小物＆ツール**
   - ライフ・得点カウンター、サイコロ（ダイス）、ターン表示
6. **ルール拡張インターフェース**
   - `OnCardPlayed`, `OnTurnEnd` などのU#イベントフック
