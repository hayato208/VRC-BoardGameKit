# VRC-BoardGameKit (仮称)

**VRChat向け 汎用ボードゲーム・カードゲーム制作パッケージ**

---

## 概要

本プロジェクトは、VRChatワールドでオリジナルのカードゲーム・ボードゲームを誰でも簡単に遊べるようにするための汎用パッケージツールです。

- **サンドボックス型基盤**: トランプやオリジナルカードを直感的に「引く・配る・手札を見る・場に出す・シャッフルする」基本動作を標準装備。
- **自作ゲーム・オリジナルルール対応**: カード画像や枚数の自由な差し替えはもちろん、Local LLMなどを活用して独自ルール（役判定やターン進行）を低コストで拡張できるプラグイン設計を採用。
- **VPM (VRChat Package Manager) 公式規格対応**: VCC経由でワンクリック導入可能。

---

## 主な機能

1. **カード＆デッキ管理**
   - 山札（デッキ）のシャッフル・ドロー・リセット
   - 捨て札（ディスカードパイル）の集約
   - 任意の枚数・カード画像テクスチャの差し替え
2. **大迫力大判カード ＆ 両面VRシェーダー**
   - 1.2mアバター視覚最適化（幅70cm × 高さ98cm）
   - VRシングルパスステレオ（SPS-I）対応両面シェーダー（裏面左右反転補正）
3. **オブジェクトプール方式 ＆ 表裏両面Quad山札**
   - VRChat完全同期を保証するシーン事前生成カードプール（5〜100枚可変）
   - 側面メッシュレスの洗練された両面Quad山札 ＆ 視線ホバー時動的残数HUD（Zero-Traffic）
4. **統合GUIエディタ（Deck & Card Editor ＆ Arcade Field Builder）**
   - **Arcade Field Builder**: 視野角・弦長一元方程式に基づく円弧スロット空間（1〜10枠）の一発シーン生成
   - **Deck & Card Editor**: 山札プール総数の動的増減、全カード表裏統一、複数選択一括割当、連番画像D&D自動ソート流し込み
5. **プレイヤー包囲型円弧コックピット（Arcade Cockpit Layout）**
   - プレイヤー中心の等距離円弧配置（チルト角12度・下端収束対策済み）
   - 参加登録キューブ連動の動的出現パーソナル手札スロット（Zero-Traffic）
   - 二重着席防止（着席排他制御）
6. **自律吸着スナップ（Tell, Don't Ask 原則）**
   - カード自身の姿勢自己制御（`SnapTo`, `FreezeInAir`）
   - 最短距離＆重なり判定（Best Fit Snap: 大判カードでも隣接枠への誤吸着ゼロ）
7. **ポータブル4大AIエージェント体制 (`agents/`)**
   - Architect, Coder, Refactorer, UdonInspector による専門分業パイプライン開発（Red ➔ Green ➔ Refactor ➔ Audit）
