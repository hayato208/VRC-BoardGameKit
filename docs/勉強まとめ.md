・VRChatでインタラクトするオブジェクトは
**public override void Interact()**

・PrefabはInspectorのOverrides→Apply Allで初期状態を更新できる

・x,y,z軸の調整

| 軸      | ギズモの色         | 移動の方向                     | 回転させたときの動き（串刺しイメージ）              | 航空・船の用語        |
| ------ | ------------- | ------------------------- | -------------------------------- | -------------- |
| **X軸** | **赤 (Red)**   | **水平・左右**（+X: 右 / -X: 左）  | **上下にお辞儀する / うなずく**（左右に串を刺して回す）  | **Pitch（ピッチ）** |
| **Y軸** | **緑 (Green)** | **垂直・上下**（+Y: 上 / -Y: 下）  | **左右を振り向く / 首を横に振る**（縦に串を刺して回す）  | **Yaw（ヨー）**    |
| **Z軸** | **青 (Blue)**  | **前後・奥行き**（+Z: 前 / -Z: 奥） | **首をかしげる / ハンドルを切る**（前後に串を刺して回す） | **Roll（ロール）**  |
