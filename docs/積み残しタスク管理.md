## 2. 状態の定義
*   **未着手**: まだ作業を開始していない状態
*   **進行中**: 現在作業中の状態
*   **レビュー待ち**: 実装完了し、ユーザー確認待ちの状態
*   **完了**: 動作確認およびドキュメント同期が完了した状態
*   **保留**: 仕様検討や外部要因により一時停止している状態

## 3. 次回対応予定（Next Action - クリック選択＆アクション方式への移行）

### 概要
従来の「手で掴んで運ぶ（物理Pickup）」仕様から、**「視線を合わせてクリックして選択・アクションを起こす（Interact）」仕様** への移行を、1機能ずつ安全に進めます。

*   **BOOTH配布版**: 1クリックで即座に場に出る「即時モード (`Immediate`)」
*   **開発・オリジナルルール版**: 複数枚選んで手元ボタンで出す「複数選択モード (`MultiSelect`)」
*   **物理コードの温存**: `VRCPickup.pickupable = false` で掴みを無効化しつつ、物理移動・スナップコード自体は残してモード切替に対応。

### 🔹 リファクタリング (T42): 状態変数（Runtime State）のシリアライズ除外とカプセル化 【完了】
*   **背景**:
    *   `CardSnapZone.cs`（`currentCard`, `isOccupied`）や `CardController.cs`（`currentZone`, `candidateZone`, `isSelected`）等の実行時ステートに `[SerializeField]` や `public` が付与されていたため、UnityエディタのUIイベント（uGUI Buttonクリック時のEventSystem再描画等）によってインスペクターのシリアライズ初期値で上書き・巻き戻しが発生し、マルチ挙動（一括プレイや手札スロット認識）の不整合や混乱の温床となっていた。
*   **実施内容**:
    1. **シリアライズの完全排除**:
       - `CardSnapZone` の `isOccupied`, `currentCard` から `[SerializeField]` を完全撤廃し `private` 化。
       - `CardController` の `currentZone`, `candidateZone`, `isSelected` を `private` 化し、インスペクターに露出する項目を静的設定（名前、幾何閾値、マテリアル等）のみに限定。
    2. **公開メソッド（Getter & Command）の整備（Tell原則）**:
       - `CardController` に `GetCurrentZone()`, `IsSelected()`, `ClearZone()` を新設。外部直接代入を禁止し、座標計算・所属記憶を不可分に行う `SnapToZone` および `ClearZone` 経由に一本化。
